toy_meter Version 2.0

Setup Utility

概要

toy_meter 是一款用于显示业余无线电设备运行状态的简易仪表应用程序。

通过 Hamlib 显示 SIG、PO、SWR、ALC 仪表。

主要功能

功能 内容
仪表 SIG / PO / SWR / ALC
VFO 显示 显示当前运行的 VFO 频率（支持 1000MHz 以下）
TIME 显示 UTC / 本地时间
FNC 发送 YAESU 新 CAT 指令
校正 PO / ALC 仪表校正
服务器功能 支持使用 Hamlib rigctld 的服务器连接

特点

  • 使用 Hamlib rigctld 运行
  • 支持 USB Serial(Server) / Network rigctld(Client) 两种连接方式
  • 支持 PO / ALC 仪表校正
  • 支持 macOS / Windows 11 / Raspberry Pi OS / Linux
注意
  • 本软件不是测量仪器，而是辅助仪表。
  • 若其他应用程序或电脑需要连接 Hamlib rigctld， 请在 Connection Type 中选择 Network rigctld。

USB(Server) 模式

在 USB Serial(Server) 模式下，toy_meter 会在本地电脑上启动 Hamlib rigctld，并与无线电设备通信。

在同一电脑上使用多个 toy_meter

同一电脑上最多可同时运行 4 个 USB(Server) 模式的 toy_meter。

可使用的端口号如下：

toy_meter PORT
第 1 个 4532
第 2 个 4534
第 3 个 4536
第 4 个 4538

若需同时监控多个无线电设备，请为每个设备使用不同的端口号。

如何启动多个 toy_meter

若需使用多个 toy_meter，可复制程序， 并为每个副本设置不同的文件名。

例如，可按无线电设备型号命名：

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

在每个 toy_meter 中分别设置无线电设备、串口、 通信速度以及 rigctld 端口号。

注意

同一个串口不能同时被多个 toy_meter 使用。 每个 toy_meter 必须连接到不同的无线电设备和串口。

确认正在使用的端口号

当启动多个 toy_meter 时， 您可以在仪表面板标题的 [USB:453x]中查看当前使用的端口号。

面板顶部会显示如下内容： 

ToyMeter V2.0 [USB:4532]

由此可确认当前 toy_meter 使用的 USB(Server) 端口。

SETUP（设置）

Connection Type（连接方式）

项目 说明
USB Serial (Server) 用于通过本地 PC 上的 rigctld 控制 USB 连接的无线电设备。 toy_meter 会启动 rigctld。
Network rigctld (Client) 用于通过网络连接到其他运行 Hamlib rigctld 的电脑。

Radio Setting（无线电设备设置）

项目 说明.1 说明.2
MFG / MODEL / RF POWER RANGE 根据无线电设备设置
OPERATING MODE Normal 正常运行
Monitor 以绿色显示可用的仪表功能。 用于 PO / ALC 仪表校正。 在 USB(Server) 模式下可确认端口号。
Debug 调试专用（可能导致响应变慢）

RF REFERENCE（PO 仪表校正）

项目 步骤
RF REFERENCE STEP-1. 将 OPERATING MODE 设置为 Monitor
STEP-2. 以最大输出的 25% 进行发射（推荐 FM 模式）
STEP-3. 点击绿色 “PO” 进行校正
STEP-4. 如有需要，可直接调整校正值 （无需执行步骤 1〜3）

ALC REFERENCE（ALC 仪表校正）

项目 步骤
ALC REFERENCE STEP-1. 将 OPERATING MODE 设置为 Monitor
STEP-2. 发射使无线电设备的 ALC 值略低于适当范围的上限 （推荐使用 WSJT-X）
STEP-3. 点击绿色 “ALC” 进行校正
STEP-4. 如有需要，可直接调整校正值 （无需执行步骤 1〜3）

下图为无线电设备的 ALC 仪表示例。 请调整使指针略高于 ▲ 标记。

注意： PO / ALC 仪表因无线电设备型号差异较大， 请仅作为参考使用。

Serial Port Setting（串口设置）

项目 说明.1 说明.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL 根据无线电设备设置
SCAN_SP 0.1 〜 0.5 数值越小，指针响应越快。 旧电脑或旧无线电设备建议使用较大数值。

注意： 通信异常时，设置界面会自动打开。

Network rigctld（网络连接）

项目 说明.1 说明.2
HOST IP ADDRESS 运行 Hamlib rigctld 的 PC(Server) 的 IP 地址。 本地时可留空或使用 127.0.0.1。
PORT PORT NO 运行 Hamlib rigctld 的 PC(Server) 的端口号。 默认值为 4532。

参考： 使用 Server 时，Server 端的 toy_meter 应设置为 USB Serial(Server)。 在连接的应用程序中指定运行 toy_meter 的 PC 的 IP 地址和端口号。

例如： 

192.168.1.100:4532

Custom Functions（自定义功能）

项目 说明.1 说明.2
FNCx 第 1 参数 显示标签（最多 7 个字符）
第 2 参数 控制指令（最多 16 个字符）

注意： 此功能为 YAESU 新 CAT 指令设计。 不保证在其他无线电设备上可用。

  • 不支持需要响应的指令。
  • 若指令执行时间过长，设置界面可能会打开。 不建议使用此类指令。
  • 请仅在了解无线电设备通信规格（CAT 指令）的情况下使用。

Setup & Exit（设置与退出）

项目 说明
右下 JP1RXQ 设置（Setup）界面
左上 S 退出（仅适用于 Raspberry Pi 320×480 显示器）
右上 W TUNE（仅适用于 YAESU 新 CAT 指令）

支持环境

与电台通信需要 Hamlib / rigctld。

推荐设置

环境 推荐 SCAN_SP 值
Apple Silicon 0.1 〜 0.2
Windows 11 0.1 〜 0.2
Raspberry Pi 3B+ 0.3 〜 0.5
连接速度 9600bps 0.3 〜 0.5
连接速度 38400bps 0.1 〜 0.3
