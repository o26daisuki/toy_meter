toy_meter Version 2.0

Setup Utility

Resumen

toy_meter es una aplicación de medidor simple que muestra el estado de operación de un transceptor de radioaficionado.

Muestra los medidores SIG, PO, SWR y ALC a través de Hamlib.

Funciones principales

Función Contenido
Medidor SIG / PO / SWR / ALC
Visualización VFO Visualización de la frecuencia VFO en operación (compatible con menos de 1000 MHz)
Visualización TIME UTC / Hora local
FNC Envío de comandos CAT nuevos de YAESU
Corrección Corrección de los medidores PO / ALC
Función de servidor Compatible con conexión de servidor usando Hamlib rigctld

Características

  • Funciona utilizando Hamlib rigctld
  • Compatible con dos tipos de conexión: USB Serial(Server) / Network rigctld(Client)
  • Compatible con corrección de medidores PO / ALC
  • Compatible con macOS / Windows 11 / Raspberry Pi OS / Linux
Nota
  • Este software no es un instrumento de medición, sino un medidor auxiliar.
  • Si otras aplicaciones o PCs se conectan a Hamlib rigctld, utilice Network rigctld en Connection Type.

Modo USB(Server)

En el modo USB Serial(Server), toy_meter inicia Hamlib rigctld en el PC local y se comunica con el transceptor.

Uso de múltiples toy_meter en el mismo PC

En el mismo PC, se pueden iniciar simultáneamente hasta 4 instancias de toy_meter en modo USB(Server).

Los números de puerto disponibles son los siguientes:

toy_meter PORT
1ª unidad 4532
2ª unidad 4534
3ª unidad 4536
4ª unidad 4538

Si se monitorean varios transceptores simultáneamente en el mismo PC, utilice diferentes números de puerto para cada uno.

Cómo iniciar múltiples toy_meter

Si desea usar múltiples toy_meter, copie el programa y asígnele nombres de archivo diferentes.

Por ejemplo, puede nombrarlos según el modelo del transceptor:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

En cada toy_meter configure el transceptor, el puerto serial, la velocidad de comunicación y el número de puerto de rigctld de manera individual.

Nota

No es posible usar el mismo puerto serial en múltiples toy_meter. Conecte cada toy_meter a un transceptor y puerto serial diferente.

Confirmar el número de puerto en uso

Cuando se inician varios toy_meter, puede comprobar el número de puerto que está utilizando actualmente en el título del panel del medidor [USB:453x].

En la parte superior del panel se mostrará algo como: 

ToyMeter V2.0 [USB:4532]

Esto permite verificar qué puerto USB(Server) está usando actualmente cada toy_meter.

SETUP (Configuración)

Connection Type (Tipo de conexión)

Ítem Descripción
USB Serial (Server) Para controlar un transceptor conectado por USB mediante rigctld en el PC local. toy_meter inicia rigctld.
Network rigctld (Client) Para conectarse a Hamlib rigctld ejecutándose en otro PC a través de la red.

Radio Setting (Configuración del transceptor)

Ítem Descripción.1 Descripción.2
MFG / MODEL / RF POWER RANGE Configurar según el transceptor
OPERATING MODE Normal Operación normal
Monitor Verifica las funciones de medidor disponibles en verde. También se utiliza para la corrección de los medidores PO / ALC. En modo USB(Server) permite confirmar el número de puerto en uso.
Debug Modo exclusivo para depuración (puede ralentizar la respuesta)

RF REFERENCE (Corrección del medidor PO)

Ítem Procedimiento
RF REFERENCE STEP-1. Configure OPERATING MODE en Monitor
STEP-2. Transmita al 25% de la potencia máxima (se recomienda modo FM)
STEP-3. Haga clic en “PO” en verde para corregir
STEP-4. Ajuste manualmente el valor de corrección si es necesario (puede configurarse sin realizar los pasos 1–3)

ALC REFERENCE (Corrección del medidor ALC)

Ítem Procedimiento
ALC REFERENCE STEP-1. Configure OPERATING MODE en Monitor
STEP-2. Transmita de manera que la aguja quede ligeramente por debajo del límite superior del rango adecuado de ALC del transceptor (se recomienda usar WSJT-X)
STEP-3. Haga clic en “ALC” en verde para corregir
STEP-4. Ajuste manualmente el valor de corrección si es necesario (puede configurarse sin realizar los pasos 1–3)

La siguiente imagen muestra el medidor ALC del transceptor. Ajuste para que la aguja quede ligeramente por encima de la marca ▲.

Nota: Los medidores PO / ALC varían significativamente según el modelo del transceptor. Utilícelos solo como referencia.

Serial Port Setting (Configuración de conexión serial)

Ítem Descripción.1 Descripción.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Configurar según el transceptor
SCAN_SP 0.1 〜 0.5 Cuanto menor sea el valor, mejor será la respuesta de la aguja. Se recomienda un valor mayor para PCs o transceptores antiguos.

Nota: En caso de error de comunicación, la pantalla de configuración se abrirá automáticamente.

Network rigctld (Conexión de red)

Ítem Descripción.1 Descripción.2
HOST IP ADDRESS Dirección IP del PC(Server) donde se ejecuta Hamlib rigctld. En modo local, dejar en blanco o usar 127.0.0.1.
PORT PORT NO Número de puerto del PC(Server) donde se ejecuta Hamlib rigctld. El valor predeterminado es 4532.

Referencia: Si se utiliza Server, configure Connection Type en USB Serial(Server) en el lado del servidor. En la aplicación cliente, especifique la dirección IP y el número de puerto del PC donde se ejecuta toy_meter.

Ejemplo: 

192.168.1.100:4532

Custom Functions (Funciones personalizadas)

Ítem Descripción.1 Descripción.2
FNCx Primer parámetro Etiqueta de visualización (máx. 7 caracteres)
Segundo parámetro Comando de control (máx. 16 caracteres)

Nota: Función implementada para los nuevos comandos CAT de YAESU. No se garantiza su funcionamiento con otros transceptores.

  • No es compatible con comandos que requieran respuesta.
  • Si el tiempo de espera del comando es largo, puede abrirse la pantalla de configuración. No se recomienda usar este tipo de comandos.
  • Utilícelo solo si comprende las especificaciones de comunicación (comandos CAT) del transceptor.

Setup & Exit (Configuración y salida)

Ítem Descripción
Abajo derecha JP1RXQ Pantalla de configuración (Setup)
Arriba izquierda S Salir (solo para pantalla Raspberry Pi 320×480)
Arriba derecha W TUNE (solo para nuevos comandos CAT de YAESU)
