toy_meter Version 2.0

Setup Utility

Översikt

toy_meter är ett enkelt mätarprogram som visar driftstatus för en amatörradio.

Det visar SIG-, PO-, SWR- och ALC-mätare via Hamlib.

Huvudfunktioner

Funktion Innehåll
Mätare SIG / PO / SWR / ALC
VFO-visning Visning av aktiv VFO-frekvens (stöd för under 1000 MHz)
TID-visning UTC / Lokal tid
FNC Skickar nya YAESU CAT-kommandon
Korrigering Korrigering av PO / ALC-mätare
Serverfunktion Stöd för serveranslutning via Hamlib rigctld

Egenskaper

  • Fungerar med Hamlib rigctld
  • Stöd för två anslutningstyper: USB Serial(Server) / Network rigctld(Client)
  • Stöd för korrigering av PO / ALC-mätare
  • Kompatibel med macOS / Windows 11 / Raspberry Pi OS / Linux
Observera
  • Detta program är inte ett mätinstrument utan en hjälpmätare.
  • Om andra applikationer eller datorer ansluter till Hamlib rigctld, använd Network rigctld i Connection Type.

USB(Server)-läge

I USB Serial(Server)-läge startar toy_meter Hamlib rigctld på den lokala datorn och kommunicerar med radion.

Användning av flera toy_meter på samma dator

På samma dator kan upp till 4 instanser av toy_meter köras samtidigt i USB(Server)-läge.

Tillgängliga portnummer är följande:

toy_meter PORT
1:a instansen 4532
2:a instansen 4534
3:e instansen 4536
4:e instansen 4538

Om flera radion används samtidigt på samma dator, använd olika portnummer för varje radio.

Hur man startar flera toy_meter

För att använda flera toy_meter, kopiera programmet och ge varje kopia ett eget filnamn.

Du kan till exempel namnge dem efter radion:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

I varje toy_meter ställer du in radio, serieport, kommunikationshastighet och rigctld-portnummer individuellt.

Observera

Samma serieport kan inte användas av flera toy_meter. Anslut varje toy_meter till en separat radio och serieport.

Kontrollera portnumret som används

När flera toy_meter startas, kan du kontrollera numret på den port som används för närvarande i mätarpanelens titel [USB:453x].

Överst på panelen visas till exempel: 

ToyMeter V2.0 [USB:4532]

Detta visar vilken USB(Server)-port som används av varje instans.

SETUP (Inställningar)

Connection Type (Anslutningstyp)

Post Beskrivning
USB Serial (Server) När en USB-ansluten radio styrs via rigctld på den lokala datorn. toy_meter startar rigctld.
Network rigctld (Client) När anslutning sker via nätverk till en annan dator som kör Hamlib rigctld.

Radio Setting (Radioinställningar)

Post Beskrivning.1 Beskrivning.2
MFG / MODEL / RF POWER RANGE Ställ in enligt radion
OPERATING MODE Normal Normal drift
Monitor Visar tillgängliga mätarfunktioner i grönt. Används även för korrigering av PO / ALC-mätare. I USB(Server)-läge kan du kontrollera portnumret.
Debug Endast för felsökning (kan ge långsammare respons)

RF REFERENCE (PO-mätarkorrigering)

Post Procedur
RF REFERENCE STEP-1. Ställ OPERATING MODE till Monitor
STEP-2. Sänd med 25% av maximal effekt (FM-läge rekommenderas)
STEP-3. Klicka på den gröna “PO” för korrigering
STEP-4. Justera korrigeringsvärdet manuellt vid behov (steg 1–3 är inte obligatoriska)

ALC REFERENCE (ALC-mätarkorrigering)

Post Procedur
ALC REFERENCE STEP-1. Ställ OPERATING MODE till Monitor
STEP-2. Sänd så att ALC-värdet ligger strax under den övre gränsen (WSJT-X rekommenderas)
STEP-3. Klicka på den gröna “ALC” för korrigering
STEP-4. Justera korrigeringsvärdet manuellt vid behov (steg 1–3 är inte obligatoriska)

Nedan visas ett exempel på ALC-mätaren på radion. Justera så att nålen ligger strax ovanför ▲-markeringen.

Observera: PO / ALC-mätare varierar mycket beroende på radiomodell. Använd dem endast som riktlinje.

Serial Port Setting (Serieportsinställningar)

Post Beskrivning.1 Beskrivning.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Ställ in enligt radion
SCAN_SP 0.1 〜 0.5 Lägre värde ger snabbare nålrespons. För äldre datorer och radioapparater rekommenderas ett högre värde.

Observera: Vid kommunikationsfel öppnas inställningsskärmen automatiskt.

Network rigctld (Nätverksanslutning)

Post Beskrivning.1 Beskrivning.2
HOST IP ADDRESS IP-adress för datorn (Server) som kör Hamlib rigctld. Vid lokal användning: lämna tomt eller använd 127.0.0.1.
PORT PORT NO Portnummer för datorn (Server) som kör Hamlib rigctld. Standard är 4532.

Referens: Vid användning av Server-läge ska toy_meter på serversidan ha Connection Type inställt på USB Serial(Server). I klientapplikationen anger du IP-adress och portnummer för datorn där toy_meter körs.

Exempel: 

192.168.1.100:4532

Custom Functions (Anpassade funktioner)

Post Beskrivning.1 Beskrivning.2
FNCx Första parametern Visningsetikett (max 7 tecken)
Andra parametern Styrkommando (max 16 tecken)

Observera: Denna funktion är implementerad för nya YAESU CAT-kommandon. Funktion med andra radioapparater garanteras inte.

  • Stöder inte kommandon som kräver svar.
  • Om kommandot tar lång tid kan inställningsskärmen öppnas. Användning av sådana kommandon rekommenderas inte.
  • Använd endast om du förstår radioapparatens kommunikationsspecifikationer (CAT-kommandon).

Setup & Exit (Inställningar och avslutning)

Post Beskrivning
Nedre högra hörnet JP1RXQ Inställningsskärm (Setup)
Övre vänstra hörnet S Avsluta (endast för Raspberry Pi 320×480-skärm)
Övre högra hörnet W TUNE (endast för nya YAESU CAT-kommandon)
