toy_meter Version 2.0

Setup Utility

Visão geral

toy_meter é um aplicativo simples de medição que exibe o estado operacional de um transceptor de rádio amador.

Ele exibe os medidores SIG, PO, SWR e ALC através do Hamlib.

Principais funções

Função Conteúdo
Medidor SIG / PO / SWR / ALC
Exibição VFO Exibição da frequência VFO em operação (compatível com menos de 1000 MHz)
Exibição TIME UTC / Hora local
FNC Envio de novos comandos CAT da YAESU
Correção Correção dos medidores PO / ALC
Função de servidor Compatível com conexão de servidor usando Hamlib rigctld

Características

  • Funciona utilizando Hamlib rigctld
  • Compatível com dois tipos de conexão: USB Serial(Server) / Network rigctld(Client)
  • Compatível com correção dos medidores PO / ALC
  • Compatível com macOS / Windows 11 / Raspberry Pi OS / Linux
Aviso
  • Este software não é um instrumento de medição, mas sim um medidor auxiliar.
  • Se outros aplicativos ou PCs se conectarem ao Hamlib rigctld, utilize Network rigctld em Connection Type.

Modo USB(Server)

No modo USB Serial(Server), o toy_meter inicia o Hamlib rigctld no PC local e se comunica com o transceptor.

Uso de múltiplos toy_meter no mesmo PC

No mesmo PC, é possível executar simultaneamente até 4 instâncias do toy_meter no modo USB(Server).

Os números de porta disponíveis são os seguintes:

toy_meter PORT
1ª instância 4532
2ª instância 4534
3ª instância 4536
4ª instância 4538

Se vários transceptores forem monitorados simultaneamente no mesmo PC, utilize números de porta diferentes para cada um.

Como iniciar múltiplos toy_meter

Para usar várias instâncias do toy_meter, copie o programa e atribua nomes de arquivos diferentes para cada cópia.

Por exemplo, você pode nomeá-los de acordo com o modelo do transceptor:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

Em cada toy_meter, configure individualmente o transceptor, a porta serial, a velocidade de comunicação e o número da porta rigctld.

Aviso

Não é possível usar a mesma porta serial em várias instâncias do toy_meter. Conecte cada toy_meter a um transceptor e porta serial diferentes.

Verificar o número da porta em uso

Quando várias instâncias do toy_meter são iniciadas, você pode verificar o número da porta atualmente em uso no título do painel do medidor [USB:453x].

Na parte superior do painel será exibido, por exemplo: 

ToyMeter V2.0 [USB:4532]

Isso permite verificar qual porta USB(Server) está sendo utilizada por cada instância.

SETUP (Configuração)

Connection Type (Tipo de conexão)

Item Descrição
USB Serial (Server) Para controlar um transceptor conectado via USB usando rigctld no PC local. O toy_meter inicia o rigctld.
Network rigctld (Client) Para conectar-se pela rede a outro PC que esteja executando Hamlib rigctld.

Radio Setting (Configuração do transceptor)

Item Descrição.1 Descrição.2
MFG / MODEL / RF POWER RANGE Configurar de acordo com o transceptor
OPERATING MODE Normal Operação normal
Monitor Exibe em verde as funções de medição disponíveis. Também é usado para a correção dos medidores PO / ALC. No modo USB(Server), permite verificar a porta em uso.
Debug Modo exclusivo para depuração (pode deixar a resposta mais lenta)

RF REFERENCE (Correção do medidor PO)

Item Procedimento
RF REFERENCE STEP-1. Configure OPERATING MODE para Monitor
STEP-2. Transmita com 25% da potência máxima (modo FM recomendado)
STEP-3. Clique no “PO” verde para corrigir
STEP-4. Ajuste manualmente o valor de correção, se necessário (os passos 1–3 não são obrigatórios)

ALC REFERENCE (Correção do medidor ALC)

Item Procedimento
ALC REFERENCE STEP-1. Configure OPERATING MODE para Monitor
STEP-2. Transmita de forma que o valor ALC fique ligeiramente abaixo do limite superior da faixa adequada (recomendado usar WSJT-X)
STEP-3. Clique no “ALC” verde para corrigir
STEP-4. Ajuste manualmente o valor de correção, se necessário (os passos 1–3 não são obrigatórios)

A imagem abaixo mostra o medidor ALC do transceptor. Ajuste para que o ponteiro fique um pouco acima do símbolo ▲.

Aviso: Os medidores PO / ALC variam significativamente conforme o modelo do transceptor. Use-os apenas como referência.

Serial Port Setting (Configuração da porta serial)

Item Descrição.1 Descrição.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Configurar de acordo com o transceptor
SCAN_SP 0.1 〜 0.5 Quanto menor o valor, melhor a resposta do ponteiro. Para PCs ou transceptores antigos, recomenda-se um valor maior.

Aviso: Em caso de erro de comunicação, a tela de configuração será aberta automaticamente.

Network rigctld (Conexão de rede)

Item Descrição.1 Descrição.2
HOST IP ADDRESS Endereço IP do PC(Server) que executa Hamlib rigctld. Para uso local, deixe em branco ou use 127.0.0.1.
PORT PORT NO Número da porta do PC(Server) que executa Hamlib rigctld. O padrão é 4532.

Referência: Ao usar o modo Server, configure Connection Type como USB Serial(Server) no lado do servidor. No aplicativo cliente, especifique o endereço IP e o número da porta do PC onde o toy_meter está em execução.

Exemplo: 

192.168.1.100:4532

Custom Functions (Funções personalizadas)

Item Descrição.1 Descrição.2
FNCx Primeiro parâmetro Etiqueta de exibição (máx. 7 caracteres)
Segundo parâmetro Comando de controle (máx. 16 caracteres)

Aviso: Função implementada para novos comandos CAT da YAESU. Não há garantia de funcionamento em outros transceptores.

  • Não suporta comandos que exigem resposta.
  • Se o tempo de execução do comando for longo, a tela de configuração pode ser aberta. Não é recomendado usar tais comandos.
  • Use apenas se você compreender as especificações de comunicação (comandos CAT) do transceptor.

Setup & Exit (Configuração e saída)

Item Descrição
Canto inferior direito JP1RXQ Tela de configuração (Setup)
Canto superior esquerdo S Encerrar (somente para display Raspberry Pi 320×480)
Canto superior direito W TUNE (somente para novos comandos CAT da YAESU)

Ambiente compatível

Hamlib / rigctld é necessário para a comunicação com o transceptor.
