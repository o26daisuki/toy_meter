toy_meter Version 2.0

Setup Utility

ภาพรวม

toy_meter เป็นแอปพลิเคชันมิเตอร์แบบง่ายที่ใช้แสดงสถานะการทำงานของวิทยุสมัครเล่น

แสดงมิเตอร์ SIG, PO, SWR และ ALC ผ่าน Hamlib

ฟังก์ชันหลัก

ฟังก์ชัน เนื้อหา
มิเตอร์ SIG / PO / SWR / ALC
แสดง VFO แสดงความถี่ VFO ที่กำลังใช้งาน (รองรับต่ำกว่า 1000MHz)
แสดงเวลา TIME UTC / เวลาท้องถิ่น
FNC ส่งคำสั่ง CAT ใหม่ของ YAESU
การปรับเทียบ ปรับเทียบมิเตอร์ PO / ALC
ฟังก์ชันเซิร์ฟเวอร์ รองรับการเชื่อมต่อเซิร์ฟเวอร์ผ่าน Hamlib rigctld

คุณลักษณะ

  • ทำงานโดยใช้ Hamlib rigctld
  • รองรับการเชื่อมต่อ 2 แบบ: USB Serial(Server) / Network rigctld(Client)
  • รองรับการปรับเทียบมิเตอร์ PO / ALC
  • รองรับ macOS / Windows 11 / Raspberry Pi OS / Linux
ข้อควรระวัง
  • ซอฟต์แวร์นี้ไม่ใช่อุปกรณ์วัด แต่เป็นมิเตอร์เสริม
  • หากแอปพลิเคชันหรือคอมพิวเตอร์อื่นต้องการเชื่อมต่อกับ Hamlib rigctld ให้ใช้ Network rigctld ใน Connection Type

โหมด USB(Server)

ในโหมด USB Serial(Server) toy_meter จะเริ่ม Hamlib rigctld บนคอมพิวเตอร์เครื่องนั้นและสื่อสารกับวิทยุ

การใช้ toy_meter หลายตัวบนคอมพิวเตอร์เดียวกัน

สามารถเปิด toy_meter ในโหมด USB(Server) ได้พร้อมกันสูงสุด 4 ตัว บนคอมพิวเตอร์เครื่องเดียว

หมายเลขพอร์ตที่สามารถใช้ได้มีดังนี้:

toy_meter PORT
ตัวที่ 1 4532
ตัวที่ 2 4534
ตัวที่ 3 4536
ตัวที่ 4 4538

หากต้องการมอนิเตอร์วิทยุหลายเครื่องพร้อมกันบนคอมพิวเตอร์เดียว ให้ใช้หมายเลขพอร์ตที่แตกต่างกันสำหรับแต่ละเครื่อง

วิธีเปิด toy_meter หลายตัว

หากต้องการใช้ toy_meter หลายตัว ให้คัดลอกโปรแกรม และตั้งชื่อไฟล์ใหม่ตามต้องการสำหรับแต่ละตัว

ตัวอย่างเช่น ตั้งชื่อตามรุ่นวิทยุ:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

แต่ละ toy_meter ต้องตั้งค่ารุ่นวิทยุ พอร์ตซีเรียล ความเร็วสื่อสาร และหมายเลขพอร์ต rigctld แยกกัน

ข้อควรระวัง

ไม่สามารถใช้พอร์ตซีเรียลเดียวกันกับ toy_meter หลายตัวได้ แต่ละตัวต้องเชื่อมต่อกับวิทยุและพอร์ตซีเรียลที่แตกต่างกัน

ตรวจสอบหมายเลขพอร์ตที่ใช้งานอยู่

เมื่อเปิดใช้งาน toy_meter หลายตัว คุณสามารถตรวจสอบหมายเลขพอร์ตที่กำลังใช้งานอยู่ได้จาก ชื่อหัวข้อของแผงมิเตอร์ [USB:453x]

ด้านบนของหน้าจอจะแสดงตัวอย่างเช่น: 

ToyMeter V2.0 [USB:4532]

ทำให้ทราบว่า toy_meter ตัวนั้นกำลังใช้พอร์ต USB(Server) หมายเลขใด

SETUP (การตั้งค่า)

Connection Type (ประเภทการเชื่อมต่อ)

รายการ คำอธิบาย
USB Serial (Server) ใช้ควบคุมวิทยุที่เชื่อมต่อผ่าน USB โดยใช้ rigctld บนคอมพิวเตอร์เครื่องนั้น toy_meter จะเริ่มการทำงานของ rigctld
Network rigctld (Client) ใช้เชื่อมต่อผ่านเครือข่ายไปยังคอมพิวเตอร์เครื่องอื่นที่กำลังรัน Hamlib rigctld

Radio Setting (การตั้งค่าวิทยุ)

รายการ คำอธิบาย.1 คำอธิบาย.2
MFG / MODEL / RF POWER RANGE ตั้งค่าตามรุ่นวิทยุ
OPERATING MODE Normal โหมดใช้งานปกติ
Monitor แสดงฟังก์ชันมิเตอร์ที่สามารถใช้ได้เป็นสีเขียว ใช้สำหรับปรับเทียบมิเตอร์ PO / ALC และตรวจสอบหมายเลขพอร์ตในโหมด USB(Server)
Debug โหมดสำหรับดีบัก (อาจทำให้การตอบสนองช้าลง)

RF REFERENCE (การปรับเทียบมิเตอร์ PO)

รายการ ขั้นตอน
RF REFERENCE STEP-1. ตั้ง OPERATING MODE เป็น Monitor
STEP-2. ส่งสัญญาณที่ 25% ของกำลังสูงสุด (แนะนำโหมด FM)
STEP-3. คลิก “PO” สีเขียวเพื่อทำการปรับเทียบ
STEP-4. หากจำเป็นสามารถปรับค่าการเทียบเองได้ (ไม่จำเป็นต้องทำขั้นตอน 1–3)

ALC REFERENCE (การปรับเทียบมิเตอร์ ALC)

รายการ ขั้นตอน
ALC REFERENCE STEP-1. ตั้ง OPERATING MODE เป็น Monitor
STEP-2. ส่งสัญญาณให้ระดับ ALC อยู่ต่ำกว่าขีดบนเล็กน้อย (แนะนำให้ใช้ WSJT-X)
STEP-3. คลิก “ALC” สีเขียวเพื่อทำการปรับเทียบ
STEP-4. หากจำเป็นสามารถปรับค่าการเทียบเองได้ (ไม่จำเป็นต้องทำขั้นตอน 1–3)

ด้านล่างเป็นตัวอย่างมิเตอร์ ALC ของวิทยุ ปรับให้เข็มอยู่สูงกว่าสัญลักษณ์ ▲ เล็กน้อย

ข้อควรระวัง: มิเตอร์ PO / ALC แตกต่างกันมากตามรุ่นวิทยุ ใช้เป็นข้อมูลอ้างอิงเท่านั้น

Serial Port Setting (การตั้งค่าพอร์ตซีเรียล)

รายการ คำอธิบาย.1 คำอธิบาย.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL ตั้งค่าตามวิทยุ
SCAN_SP 0.1 〜 0.5 ค่ายิ่งน้อย เข็มจะตอบสนองเร็วขึ้น สำหรับคอมพิวเตอร์หรือวิทยุรุ่นเก่า แนะนำให้ใช้ค่ามากขึ้น

ข้อควรระวัง: หากเกิดข้อผิดพลาดในการสื่อสาร หน้าจอตั้งค่าจะเปิดขึ้นโดยอัตโนมัติ

Network rigctld (การเชื่อมต่อเครือข่าย)

รายการ คำอธิบาย.1 คำอธิบาย.2
HOST IP ADDRESS ที่อยู่ IP ของคอมพิวเตอร์ (Server) ที่รัน Hamlib rigctld หากใช้งานภายในเครื่อง ให้เว้นว่างหรือใช้ 127.0.0.1
PORT PORT NO หมายเลขพอร์ตของคอมพิวเตอร์ (Server) ที่รัน Hamlib rigctld ค่าเริ่มต้นคือ 4532

ข้อมูลเพิ่มเติม: หากใช้โหมด Server ให้ตั้งค่า Connection Type ของ toy_meter ฝั่งเซิร์ฟเวอร์เป็น USB Serial(Server) ในแอปพลิเคชันที่เชื่อมต่อ ให้ระบุ IP และหมายเลขพอร์ตของคอมพิวเตอร์ที่รัน toy_meter

ตัวอย่าง: 

192.168.1.100:4532

Custom Functions (ฟังก์ชันกำหนดเอง)

รายการ คำอธิบาย.1 คำอธิบาย.2
FNCx พารามิเตอร์ที่ 1 ป้ายแสดงผล (สูงสุด 7 ตัวอักษร)
พารามิเตอร์ที่ 2 คำสั่งควบคุม (สูงสุด 16 ตัวอักษร)

ข้อควรระวัง: ฟังก์ชันนี้พัฒนาสำหรับคำสั่ง CAT ใหม่ของ YAESU ไม่รับประกันการทำงานกับวิทยุรุ่นอื่น

  • ไม่รองรับคำสั่งที่ต้องการการตอบกลับ
  • หากคำสั่งใช้เวลานาน หน้าจอตั้งค่าอาจเปิดขึ้น ไม่แนะนำให้ใช้คำสั่งประเภทนี้
  • ควรใช้เฉพาะผู้ที่เข้าใจสเปกการสื่อสาร (CAT commands) ของวิทยุ

Setup & Exit (การตั้งค่าและออกจากโปรแกรม)

รายการ คำอธิบาย
มุมขวาล่าง JP1RXQ หน้าจอตั้งค่า (Setup)
มุมซ้ายบน S ออกจากโปรแกรม (เฉพาะหน้าจอ Raspberry Pi 320×480)
มุมขวาบน W TUNE (เฉพาะคำสั่ง CAT ใหม่ของ YAESU)
