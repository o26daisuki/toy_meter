toy_meter Version 2.0

Setup Utility

개요

toy_meter는 아마추어 무선기의 운용 상태를 표시하는 간단한 미터 애플리케이션입니다.

Hamlib를 통해 SIG, PO, SWR, ALC 미터를 표시합니다.

주요 기능

기능 내용
미터 SIG / PO / SWR / ALC
VFO 표시 운용 중인 VFO 주파수 표시 (1000MHz 미만 지원)
TIME 표시 UTC / 로컬 시간
FNC YAESU 신규 CAT 명령 전송
보정 PO / ALC 미터 보정
서버 기능 Hamlib rigctld를 이용한 서버 연결 지원

특징

  • Hamlib rigctld를 이용하여 동작
  • USB Serial(Server) / Network rigctld(Client) 두 가지 연결 방식 지원
  • PO / ALC 미터 보정 지원
  • macOS / Windows 11 / Raspberry Pi OS / Linux 지원
주의
  • 본 소프트웨어는 측정기가 아닌 보조 미터입니다.
  • 다른 애플리케이션이나 PC에서 Hamlib rigctld에 접속하는 경우, Connection Type에서 Network rigctld를 사용하십시오.

USB(Server) 모드

USB Serial(Server) 모드에서는 toy_meter가 로컬 PC에서 Hamlib rigctld를 실행하여 무선기와 통신합니다.

동일 PC에서 여러 toy_meter 사용하기

동일 PC에서는 USB(Server) 모드의 toy_meter를 최대 4개까지 동시에 실행할 수 있습니다.

사용 가능한 포트 번호는 다음과 같습니다.

toy_meter PORT
1대 4532
2대 4534
3대 4536
4대 4538

동일 PC에서 여러 무선기를 동시에 모니터링하는 경우, 각각 다른 포트 번호를 사용하십시오.

여러 toy_meter를 실행하는 방법

여러 toy_meter를 사용하려면 프로그램을 복사하여 각각 원하는 파일명을 지정해 사용할 수 있습니다.

예를 들어, 다음과 같이 무선기 이름을 붙일 수 있습니다.

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

각 toy_meter에서 무선기, 시리얼 포트, 통신 속도, rigctld 포트 번호 등을 개별적으로 설정하여 사용합니다.

주의

동일한 시리얼 포트를 여러 toy_meter에서 사용할 수 없습니다. 각 toy_meter는 서로 다른 무선기 및 시리얼 포트에 연결해야 합니다.

사용 중인 포트 번호 확인하기

여러 개의 toy_meter를 실행한 경우, 미터 패널 제목의 [USB:453x]에서 현재 사용 중인 포트 번호를 확인할 수 있습니다.

패널 상단의 제목에 다음과 같이 표시됩니다. 

ToyMeter V2.0 [USB:4532]

이를 통해 현재 동작 중인 toy_meter가 어떤 USB(Server) 포트를 사용 중인지 확인할 수 있습니다.

SETUP (설정)

Connection Type (접속 방식)

항목 설명
USB Serial (Server) USB로 연결된 무선기를 로컬 PC의 rigctld로 제어하는 경우. toy_meter가 rigctld를 실행합니다.
Network rigctld (Client) 다른 PC에서 동작 중인 Hamlib rigctld에 네트워크를 통해 접속하는 경우.

Radio Setting (무선기 설정)

항목 설명.1 설명.2
MFG / MODEL / RF POWER RANGE 무선기에 맞게 설정
OPERATING MODE Normal 일반 운용
Monitor 사용 가능한 미터 기능을 녹색으로 확인합니다. PO / ALC 미터 보정에도 사용합니다. 또한 USB(Server) 모드에서는 사용 중인 포트 번호를 확인할 수 있습니다.
Debug 디버그 전용 (사용 시 응답이 느려질 수 있음)

RF REFERENCE (PO 미터 보정)

항목 절차
RF REFERENCE STEP-1. OPERATING MODE를 Monitor로 설정
STEP-2. 최대 출력의 25%로 송신 (FM 모드 권장)
STEP-3. 녹색 “PO”를 클릭하여 보정
STEP-4. 필요 시 보정 값을 직접 조정 (1〜3단계를 수행하지 않아도 설정 가능)

ALC REFERENCE (ALC 미터 보정)

항목 절차
ALC REFERENCE STEP-1. OPERATING MODE를 Monitor로 설정
STEP-2. 무선기 ALC 적정 범위의 상한보다 약간 낮게 송신 (WSJT-X 사용 권장)
STEP-3. 녹색 “ALC”를 클릭하여 보정
STEP-4. 필요 시 보정 값을 직접 조정 (1〜3단계를 수행하지 않아도 설정 가능)

아래는 무선기 ALC 미터의 이미지입니다. 바늘이 ▲ 위치보다 약간 위에 오도록 조정합니다.

주의： PO / ALC 미터는 무선기 기종에 따라 차이가 크므로 참고용으로만 사용하십시오.

Serial Port Setting (시리얼 접속 설정)

항목 설명.1 설명.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL 무선기에 맞게 설정
SCAN_SP 0.1 〜 0.5 값이 작을수록 바늘의 응답성이 향상됩니다. 오래된 PC·무선기에서는 큰 값을 권장합니다.

주의： 통신 이상 시 Setup 화면이 자동으로 열립니다.

Network rigctld (네트워크 접속)

항목 설명.1 설명.2
HOST IP ADDRESS Hamlib rigctld 운용 중 PC(Server)의 IP 주소. Local 시에는 공백 또는 127.0.0.1.
PORT PORT NO Hamlib rigctld 운용 중 PC(Server)의 PORT 번호. 기본값은 4532.

참고： Server를 이용하는 경우 Server 측 toy_meter는 Connection Type을 USB Serial(Server)로 설정합니다. 접속하는 애플리케이션에서는 toy_meter가 동작하는 PC의 IP 주소와 PORT 번호를 지정합니다.

예： 

192.168.1.100:4532

Custom Functions (커스텀 기능)

항목 설명.1 설명.2
FNCx 첫 번째 파라미터 표시 라벨 (최대 7문자)
두 번째 파라미터 제어 명령 (최대 16문자)

주의： YAESU 신규 CAT 명령용으로 구현된 기능입니다. 다른 무선기에서는 동작이 보장되지 않습니다.

  • 응답이 필요한 명령에는 대응하지 않습니다.
  • 명령 완료까지 시간이 오래 걸리는 경우, Setup 화면이 열릴 수 있습니다. 이러한 명령 사용은 권장하지 않습니다.
  • 무선기의 통신 사양(CAT 명령)을 이해하는 사용자만 이용하십시오.

Setup & Exit (설정 및 종료)

항목 설명
오른쪽 아래 JP1RXQ 설정 (Setup) 화면
왼쪽 위 S 종료 (Raspberry Pi 320×480 디스플레이 전용)
오른쪽 위 W TUNE (YAESU 신규 CAT 전용)

지원 환경

무전기와 통신하려면 Hamlib / rigctld가 필요합니다.

참고 설정

환경 SCAN_SP 권장값
Apple Silicon 0.1 〜 0.2
Windows 11 0.1 〜 0.2
Raspberry Pi 3B+ 0.3 〜 0.5
접속 속도 9600bps 0.3 〜 0.5
접속 속도 38400bps 0.1 〜 0.3
