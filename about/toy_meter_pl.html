toy_meter Version 2.0

Setup Utility

Podsumowanie

toy_meter to prosta aplikacja miernika, która wyświetla stan pracy radiostacji amatorskiej.

Wyświetla wskaźniki SIG, PO, SWR i ALC za pośrednictwem Hamlib.

Główne funkcje

Funkcja Opis
Miernik SIG / PO / SWR / ALC
Wyświetlanie VFO Wyświetlanie częstotliwości VFO podczas pracy (obsługa poniżej 1000 MHz)
Wyświetlanie TIME UTC / Czas lokalny
FNC Wysyłanie nowych poleceń CAT firmy YAESU
Korekcja Korekcja mierników PO / ALC
Funkcja serwera Obsługa połączenia serwerowego z użyciem Hamlib rigctld

Cechy

  • Działa z wykorzystaniem Hamlib rigctld
  • Obsługuje dwa typy połączeń: USB Serial(Server) / Network rigctld(Client)
  • Obsługa korekcji mierników PO / ALC
  • Kompatybilny z macOS / Windows 11 / Raspberry Pi OS / Linux
Uwaga
  • To oprogramowanie nie jest przyrządem pomiarowym, lecz pomocniczym miernikiem.
  • Jeśli inne aplikacje lub komputery łączą się z Hamlib rigctld, użyj Network rigctld w ustawieniu Connection Type.

Tryb USB(Server)

W trybie USB Serial(Server) toy_meter uruchamia Hamlib rigctld na lokalnym komputerze i komunikuje się z radiostacją.

Korzystanie z wielu instancji toy_meter na jednym komputerze

Na jednym komputerze można jednocześnie uruchomić maksymalnie 4 instancje toy_meter w trybie USB(Server).

Dostępne numery portów:

toy_meter PORT
Pierwsza instancja 4532
Druga instancja 4534
Trzecia instancja 4536
Czwarta instancja 4538

Jeśli monitorujesz kilka radiostacji jednocześnie na tym samym komputerze, użyj różnych numerów portów dla każdej z nich.

Jak uruchomić wiele instancji toy_meter

Aby korzystać z wielu instancji toy_meter, skopiuj program i nadaj każdej kopii inną nazwę pliku.

Na przykład możesz nazwać je według modelu radiostacji:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

W każdej instancji ustaw osobno radiostację, port szeregowy, prędkość komunikacji oraz numer portu rigctld.

Uwaga

Ten sam port szeregowy nie może być używany przez wiele instancji toy_meter. Podłącz każdą instancję do innej radiostacji i innego portu szeregowego.

Sprawdzanie używanego numeru portu

Po uruchomieniu wielu instancji toy_meter można sprawdzić numer aktualnie używanego portu w tytule panelu miernika [USB:453x].

Na górze panelu pojawi się na przykład: 

ToyMeter V2.0 [USB:4532]

Pozwala to sprawdzić, który port USB(Server) jest aktualnie używany.

SETUP (Ustawienia)

Connection Type (Typ połączenia)

Element Opis
USB Serial (Server) Gdy radiostacja podłączona przez USB jest sterowana przez rigctld na lokalnym komputerze. toy_meter uruchamia rigctld.
Network rigctld (Client) Gdy łączysz się przez sieć z innym komputerem, na którym działa Hamlib rigctld.

Radio Setting (Ustawienia radiostacji)

Element Opis.1 Opis.2
MFG / MODEL / RF POWER RANGE Ustaw zgodnie z radiostacją
OPERATING MODE Normal Normalna praca
Monitor Wyświetla dostępne funkcje mierników na zielono. Używany także do korekcji mierników PO / ALC. W trybie USB(Server) pozwala sprawdzić używany port.
Debug Tryb debugowania (może spowolnić reakcję)

RF REFERENCE (Korekcja miernika PO)

Element Procedura
RF REFERENCE STEP-1. Ustaw OPERATING MODE na Monitor
STEP-2. Nadaj z mocą 25% maksymalnej (zalecany tryb FM)
STEP-3. Kliknij zielony „PO”, aby skorygować
STEP-4. W razie potrzeby ręcznie dostosuj wartość korekcji (kroki 1–3 nie są obowiązkowe)

ALC REFERENCE (Korekcja miernika ALC)

Element Procedura
ALC REFERENCE STEP-1. Ustaw OPERATING MODE na Monitor
STEP-2. Nadaj tak, aby wartość ALC była nieco poniżej górnej granicy (zalecane użycie WSJT-X)
STEP-3. Kliknij zielony „ALC”, aby skorygować
STEP-4. W razie potrzeby ręcznie dostosuj wartość korekcji (kroki 1–3 nie są obowiązkowe)

Poniżej znajduje się przykład miernika ALC radiostacji. Dostosuj tak, aby wskazówka była nieco powyżej symbolu ▲.

Uwaga: Mierniki PO / ALC różnią się znacznie w zależności od modelu radiostacji. Używaj ich jedynie jako wartości orientacyjnych.

Serial Port Setting (Ustawienia portu szeregowego)

Element Opis.1 Opis.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Ustaw zgodnie z radiostacją
SCAN_SP 0.1 〜 0.5 Im mniejsza wartość, tym lepsza reakcja wskazówki. Dla starszych komputerów i radiostacji zalecana jest większa wartość.

Uwaga: W przypadku błędu komunikacji ekran ustawień otworzy się automatycznie.

Network rigctld (Połączenie sieciowe)

Element Opis.1 Opis.2
HOST IP ADDRESS Adres IP komputera (Server), na którym działa Hamlib rigctld. Lokalnie: pozostaw puste lub użyj 127.0.0.1.
PORT PORT NO Numer portu komputera (Server), na którym działa Hamlib rigctld. Domyślnie 4532.

Informacja: Przy użyciu trybu Server, toy_meter po stronie serwera powinien mieć ustawione Connection Type na USB Serial(Server). W aplikacji klienckiej należy podać adres IP i numer portu komputera, na którym działa toy_meter.

Przykład: 

192.168.1.100:4532

Custom Functions (Funkcje niestandardowe)

Element Opis.1 Opis.2
FNCx Pierwszy parametr Etykieta wyświetlania (maks. 7 znaków)
Drugi parametr Polecenie sterujące (maks. 16 znaków)

Uwaga: Funkcja zaimplementowana dla nowych poleceń CAT firmy YAESU. Nie gwarantuje działania z innymi radiostacjami.

  • Nie obsługuje poleceń wymagających odpowiedzi.
  • Jeśli czas wykonania polecenia jest długi, ekran ustawień może się otworzyć. Nie zaleca się używania takich poleceń.
  • Używaj tylko, jeśli rozumiesz specyfikację komunikacji (polecenia CAT) radiostacji.

Setup & Exit (Ustawienia i zakończenie)

Element Opis
Prawy dolny róg JP1RXQ Ekran ustawień (Setup)
Lewy górny róg S Zakończenie (tylko dla wyświetlacza Raspberry Pi 320×480)
Prawy górny róg W TUNE (tylko dla nowych poleceń CAT firmy YAESU)

Obsługiwane środowisko
