toy_meter Version 2.0

Setup Utility

Overview

toy_meter is a simple meter application for displaying the operating status of amateur radio transceivers.

SIG, PO, SWR, and ALC meters are displayed via Hamlib.

Main Features

Function Description
Meters SIG / PO / SWR / ALC
VFO Display Displays the operating VFO frequency (supports frequencies below 1000 MHz)
TIME Display UTC / Local Time
FNC Sending new YAESU CAT commands
Calibration PO / ALC meter calibration
Server Function Supports Server connections using Hamlib rigctld

Features

  • Operates using Hamlib rigctld
  • Supports two connection methods: USB Serial(Server) / Network rigctld(Client)
  • Supports PO / ALC meter calibration
  • Supports macOS / Windows 11 / Raspberry Pi OS / Linux
Note
  • This software is an auxiliary meter, not a measuring instrument.
  • When connecting to Hamlib rigctld from another application or PC, under Connection Type Network rigctld please use

USB(Server) Mode

In USB Serial(Server) mode, toy_meter starts Hamlib rigctld on the local PC and communicates with the transceiver.

Using Multiple toy_meter Instances on the Same PC

On the same PC, you can run up to four toy_meter instances simultaneously in USB(Server) mode.

The following four port numbers are available.

toy_meter PORT
1st 4532
2nd 4534
3rd 4536
4th 4538

When monitoring multiple transceivers simultaneously on the same PC, use a different port number for each one.

How to Run Multiple toy_meter Instances

To use multiple toy_meter instances, copy the toy_meter program and use a different file name for each copy.

For example, you can use the transceiver names as follows.

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

For each toy_meter, configure the transceiver, serial port, communication speed, rigctld port number, and other settings individually.

Note

The same serial port cannot be used by multiple toy_meter instances. Connect each toy_meter to a different transceiver and serial port.

Checking the Port Number in Use

When multiple toy_meter instances are started, you can check the port number currently in use in the meter panel title [USB:453x].

The title at the top of the panel will display, for example: 

ToyMeter V2.0 [USB:4532]

This allows you to check which USB(Server) port the currently running toy_meter is using.

Item Description 1 Description 2

Monitor Available meter functions are shown in green. Also used for PO / ALC meter calibration. In USB(Server) mode, you can also check the port number in use.

RF REFERENCE (PO Meter Calibration)

Item Procedure
RF REFERENCE STEP-1. Set OPERATING MODE to Monitor
STEP-2. Transmit at 25% of the maximum output power (FM Mode recommended)
STEP-3. Click the green “PO” to calibrate
STEP-4. Adjust the calibration value directly if necessary (This can be set without performing STEP-1 through STEP-3)

ALC REFERENCE (ALC Meter Calibration)

Item Procedure
ALC REFERENCE STEP-1. Set OPERATING MODE to Monitor
STEP-2. Transmit so that the level is slightly below the upper limit of the appropriate ALC range on the transceiver (Using WSJT-X or similar software is recommended)
STEP-3. Click the green “ALC” to calibrate
STEP-4. Adjust the calibration value directly if necessary (This can be set without performing STEP-1 through STEP-3)

Serial Port Setting (Serial Connection Settings)

Item Description 1 Description 2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Configure according to the transceiver
SCAN_SP 0.1 〜 0.5 The smaller the value, the better the needle response. A larger value is recommended for older PCs or older transceivers.

Note: If a communication error occurs, the Setup screen will open automatically.

Network rigctld (Network Connection)

Item Description 1 Description 2
HOST IP ADDRESS IP address of the PC (Server) running Hamlib rigctld. For Local, leave blank or use 127.0.0.1.
PORT PORT NO PORT number of the PC (Server) running Hamlib rigctld. The default is 4532.

Reference: When using a Server, the toy_meter on the Server side should use Connection Type USB Serial(Server). In the connecting application, specify the IP address and PORT number of the PC where toy_meter is running.

Example: 

192.168.1.100:4532

Custom Functions (Custom Functions)

Item Description 1 Description 2
FNCx 1st Parameter Display label (maximum 7 characters)
2nd Parameter Control command (maximum 16 characters)

Note: This function is implemented for new CAT commands from YAESU. Operation with other transceivers is not guaranteed.

  • Commands that require a response are not supported.
  • If the waiting time until command completion is too long, the Setup screen may open. Use of such commands is not recommended.
  • Use this function only if you understand the communication specifications (CAT commands) of the transceiver.
