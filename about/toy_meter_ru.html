toy_meter Version 2.0

Setup Utility

Обзор

toy_meter — это простое приложение‑индикатор, отображающее состояние работы любительской радиостанции.

Отображает индикаторы SIG, PO, SWR и ALC через Hamlib.

Основные функции

Функция Описание
Индикатор SIG / PO / SWR / ALC
Отображение VFO Отображение рабочей частоты VFO (поддержка частот ниже 1000 МГц)
Отображение TIME UTC / Местное время
FNC Отправка новых CAT‑команд YAESU
Коррекция Коррекция индикаторов PO / ALC
Функция сервера Поддержка серверного подключения через Hamlib rigctld

Особенности

  • Работает через Hamlib rigctld
  • Поддерживает два типа подключения: USB Serial(Server) / Network rigctld(Client)
  • Поддержка коррекции индикаторов PO / ALC
  • Совместим с macOS / Windows 11 / Raspberry Pi OS / Linux
Внимание
  • Это программное обеспечение не является измерительным прибором, а служит вспомогательным индикатором.
  • Если другие приложения или ПК подключаются к Hamlib rigctld, используйте Network rigctld в настройке Connection Type.

Режим USB(Server)

В режиме USB Serial(Server) toy_meter запускает Hamlib rigctld на локальном ПК и взаимодействует с радиостанцией.

Использование нескольких экземпляров toy_meter на одном ПК

На одном ПК можно одновременно запускать до 4 экземпляров toy_meter в режиме USB(Server).

Доступные номера портов:

toy_meter PORT
1‑й экземпляр 4532
2‑й экземпляр 4534
3‑й экземпляр 4536
4‑й экземпляр 4538

Если на одном ПК одновременно мониторятся несколько радиостанций, используйте разные номера портов для каждой.

Как запускать несколько экземпляров toy_meter

Чтобы использовать несколько экземпляров toy_meter, скопируйте программу и присвойте каждой копии уникальное имя файла.

Например, можно назвать их по модели радиостанции:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

В каждом экземпляре настройте радиостанцию, последовательный порт, скорость передачи данных и номер порта rigctld индивидуально.

Внимание

Один и тот же последовательный порт нельзя использовать в нескольких экземплярах toy_meter. Каждый экземпляр должен быть подключён к отдельной радиостанции и отдельному порту.

Проверка используемого номера порта

При запуске нескольких экземпляров toy_meter номер используемого в данный момент порта можно проверить в заголовке панели измерителя [USB:453x].

В верхней части панели будет отображено, например: 

ToyMeter V2.0 [USB:4532]

Это позволяет определить, какой USB(Server)‑порт используется текущим экземпляром.

SETUP (Настройки)

Connection Type (Тип подключения)

Элемент Описание
USB Serial (Server) Для управления радиостанцией, подключённой через USB, с помощью rigctld на локальном ПК. toy_meter запускает rigctld.
Network rigctld (Client) Для подключения по сети к другому ПК, на котором работает Hamlib rigctld.

Radio Setting (Настройки радиостанции)

Элемент Описание.1 Описание.2
MFG / MODEL / RF POWER RANGE Настроить в соответствии с радиостанцией
OPERATING MODE Normal Обычный режим работы
Monitor Отображает доступные функции индикаторов зелёным цветом. Используется также для коррекции индикаторов PO / ALC. В режиме USB(Server) позволяет проверить используемый порт.
Debug Режим отладки (может замедлить отклик)

RF REFERENCE (Коррекция индикатора PO)

Элемент Процедура
RF REFERENCE STEP‑1. Установить OPERATING MODE в Monitor
STEP‑2. Передавать на уровне 25% максимальной мощности (рекомендуется режим FM)
STEP‑3. Нажать зелёную кнопку «PO» для коррекции
STEP‑4. При необходимости вручную отрегулировать значение коррекции (шаги 1–3 не обязательны)

ALC REFERENCE (Коррекция индикатора ALC)

Элемент Процедура
ALC REFERENCE STEP‑1. Установить OPERATING MODE в Monitor
STEP‑2. Передавать так, чтобы значение ALC было немного ниже верхней границы допустимого диапазона (рекомендуется использование WSJT‑X)
STEP‑3. Нажать зелёную кнопку «ALC» для коррекции
STEP‑4. При необходимости вручную отрегулировать значение коррекции (шаги 1–3 не обязательны)

Ниже приведён пример индикатора ALC радиостанции. Отрегулируйте так, чтобы стрелка была немного выше отметки ▲.

Внимание: Индикаторы PO / ALC сильно различаются в зависимости от модели радиостанции. Используйте их только как ориентир.

Serial Port Setting (Настройки последовательного порта)

Элемент Описание.1 Описание.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Настроить в соответствии с радиостанцией
SCAN_SP 0.1 〜 0.5 Чем меньше значение, тем быстрее реагирует стрелка. Для старых ПК и радиостанций рекомендуется большее значение.

Внимание: При ошибке связи экран настроек откроется автоматически.

Network rigctld (Сетевое подключение)

Элемент Описание.1 Описание.2
HOST IP ADDRESS IP‑адрес ПК (Server), на котором работает Hamlib rigctld. Для локального использования оставьте пустым или используйте 127.0.0.1.
PORT PORT NO Номер порта ПК (Server), на котором работает Hamlib rigctld. По умолчанию — 4532.

Справка: При использовании режима Server на стороне сервера toy_meter должен иметь Connection Type, установленный в USB Serial(Server). В клиентском приложении укажите IP‑адрес и номер порта ПК, на котором работает toy_meter.

Пример: 

192.168.1.100:4532

Custom Functions (Пользовательские функции)

Элемент Описание.1 Описание.2
FNCx Первый параметр Метка отображения (макс. 7 символов)
Второй параметр Команда управления (макс. 16 символов)

Внимание: Функция реализована для новых CAT‑команд YAESU. Работа с другими радиостанциями не гарантируется.

  • Не поддерживает команды, требующие ответа.
  • Если выполнение команды занимает много времени, может открыться экран настроек. Использование таких команд не рекомендуется.
  • Используйте только при понимании спецификаций связи (CAT‑команд) радиостанции.

Setup & Exit (Настройки и завершение)

Элемент Описание
Правый нижний угол JP1RXQ Экран настроек (Setup)
Левый верхний угол S Завершение работы (только для дисплея Raspberry Pi 320×480)
Правый верхний угол W TUNE (только для новых CAT‑команд YAESU)

Поддерживаемая среда

Для связи с трансивером требуется Hamlib / rigctld.
