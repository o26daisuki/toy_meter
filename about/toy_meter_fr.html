toy_meter Version 2.0

Setup Utility

Résumé

toy_meter est une application de mesure simple qui affiche l’état de fonctionnement d’un émetteur-récepteur radioamateur.

Elle affiche les indicateurs SIG, PO, SWR et ALC via Hamlib.

Fonctions principales

Fonction Contenu
Mesure SIG / PO / SWR / ALC
Affichage VFO Affichage de la fréquence VFO en cours d’utilisation (compatible < 1000 MHz)
Affichage TIME UTC / Heure locale
FNC Envoi des nouveaux commandes CAT de YAESU
Correction Correction des indicateurs PO / ALC
Fonction serveur Compatible avec la connexion serveur utilisant Hamlib rigctld

Caractéristiques

  • Fonctionne avec Hamlib rigctld
  • Deux modes de connexion : USB Serial(Server) / Network rigctld(Client)
  • Compatible avec la correction des indicateurs PO / ALC
  • Compatible macOS / Windows 11 / Raspberry Pi OS / Linux
Remarque
  • Ce logiciel n’est pas un instrument de mesure, mais un indicateur auxiliaire.
  • Si d’autres applications ou PC se connectent à Hamlib rigctld, utilisez Network rigctld dans Connection Type.

Mode USB(Server)

En mode USB Serial(Server), toy_meter lance Hamlib rigctld sur le PC local et communique avec l’émetteur-récepteur.

Utilisation de plusieurs toy_meter sur le même PC

Sur un même PC, jusqu’à 4 instances de toy_meter en mode USB(Server) peuvent être exécutées simultanément.

Les numéros de port disponibles sont les suivants :

toy_meter PORT
1ère instance 4532
2ème instance 4534
3ème instance 4536
4ème instance 4538

Si plusieurs émetteurs-récepteurs sont surveillés simultanément sur le même PC, utilisez un numéro de port différent pour chacun.

Comment lancer plusieurs toy_meter

Pour utiliser plusieurs toy_meter, copiez le programme et attribuez un nom de fichier différent à chaque copie.

Par exemple, vous pouvez les nommer selon le modèle de l’émetteur-récepteur :

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

Dans chaque toy_meter, configurez individuellement l’émetteur-récepteur, le port série, la vitesse de communication et le numéro de port rigctld.

Remarque

Un même port série ne peut pas être utilisé par plusieurs toy_meter. Connectez chaque toy_meter à un émetteur-récepteur et un port série distinct.

Vérifier le numéro de port utilisé

Lorsque plusieurs instances de toy_meter sont lancées, vous pouvez vérifier le numéro du port actuellement utilisé dans le titre du panneau du compteur [USB:453x].

Le titre en haut du panneau affichera par exemple : 

ToyMeter V2.0 [USB:4532]

Cela permet de vérifier quel port USB(Server) est utilisé par chaque instance.

SETUP (Paramètres)

Connection Type (Type de connexion)

Élément Description
USB Serial (Server) Pour contrôler un émetteur-récepteur connecté en USB via rigctld sur le PC local. toy_meter lance rigctld.
Network rigctld (Client) Pour se connecter via réseau à un autre PC exécutant Hamlib rigctld.

Radio Setting (Paramètres de l’émetteur-récepteur)

Élément Description.1 Description.2
MFG / MODEL / RF POWER RANGE Configurer selon l’émetteur-récepteur
OPERATING MODE Normal Utilisation normale
Monitor Affiche en vert les fonctions de mesure disponibles. Utilisé également pour la correction des indicateurs PO / ALC. En mode USB(Server), permet de vérifier le port utilisé.
Debug Mode de débogage (peut ralentir la réponse)

RF REFERENCE (Correction du PO)

Élément Procédure
RF REFERENCE STEP-1. Régler OPERATING MODE sur Monitor
STEP-2. Transmettre à 25 % de la puissance maximale (mode FM recommandé)
STEP-3. Cliquer sur “PO” en vert pour corriger
STEP-4. Ajuster manuellement la valeur de correction si nécessaire (les étapes 1–3 ne sont pas obligatoires)

ALC REFERENCE (Correction du ALC)

Élément Procédure
ALC REFERENCE STEP-1. Régler OPERATING MODE sur Monitor
STEP-2. Transmettre de manière à rester légèrement en dessous de la limite supérieure de la plage ALC de l’émetteur-récepteur (WSJT-X recommandé)
STEP-3. Cliquer sur “ALC” en vert pour corriger
STEP-4. Ajuster manuellement la valeur de correction si nécessaire (les étapes 1–3 ne sont pas obligatoires)

Ci-dessous se trouve une image du indicateur ALC de l’émetteur-récepteur. Ajustez pour que l’aiguille soit légèrement au-dessus du repère ▲.

Remarque : Les indicateurs PO / ALC varient fortement selon le modèle de l’émetteur-récepteur. Utilisez-les uniquement comme référence.

Serial Port Setting (Paramètres du port série)

Élément Description.1 Description.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Configurer selon l’émetteur-récepteur
SCAN_SP 0.1 〜 0.5 Plus la valeur est faible, meilleure est la réactivité de l’aiguille. Pour les anciens PC ou émetteurs-récepteurs, une valeur plus élevée est recommandée.

Remarque : En cas d’erreur de communication, l’écran de configuration s’ouvrira automatiquement.

Network rigctld (Connexion réseau)

Élément Description.1 Description.2
HOST IP ADDRESS Adresse IP du PC(Server) exécutant Hamlib rigctld. En local, laisser vide ou utiliser 127.0.0.1.
PORT PORT NO Numéro de port du PC(Server) exécutant Hamlib rigctld. Valeur par défaut : 4532.

Référence : Lors de l’utilisation du mode Server, régler Connection Type sur USB Serial(Server) côté serveur. Dans l’application cliente, spécifier l’adresse IP et le numéro de port du PC exécutant toy_meter.

Exemple : 

192.168.1.100:4532

Custom Functions (Fonctions personnalisées)

Élément Description.1 Description.2
FNCx Premier paramètre Étiquette d’affichage (max. 7 caractères)
Deuxième paramètre Commande de contrôle (max. 16 caractères)

Remarque : Fonction implémentée pour les nouveaux commandes CAT de YAESU. Aucune garantie de fonctionnement avec d’autres émetteurs-récepteurs.

  • Non compatible avec les commandes nécessitant une réponse.
  • Si le temps d’exécution d’une commande est long, l’écran de configuration peut s’ouvrir. L’utilisation de telles commandes n’est pas recommandée.
  • À utiliser uniquement si vous comprenez les spécifications de communication (commandes CAT) de l’émetteur-récepteur.

Setup & Exit (Paramètres et sortie)

Élément Description
En bas à droite JP1RXQ Écran de configuration (Setup)
En haut à gauche S Quitter (réservé à l’écran Raspberry Pi 320×480)
En haut à droite W TUNE (réservé aux nouveaux commandes CAT de YAESU)

Environnement compatible

Hamlib / rigctld est requis pour la communication avec le transceiver.

Environnement Valeur SCAN_SP recommandée
