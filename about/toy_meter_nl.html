toy_meter Version 2.0

Setup Utility

Overzicht

toy_meter is een eenvoudige meterapplicatie die de bedrijfsstatus van een amateurradio toont.

Het toont de SIG-, PO-, SWR- en ALC-meters via Hamlib.

Belangrijkste functies

Functie Inhoud
Meter SIG / PO / SWR / ALC
VFO-weergave Weergave van de actieve VFO-frequentie (onder 1000 MHz ondersteund)
TIME-weergave UTC / Lokale tijd
FNC Verzenden van nieuwe YAESU CAT-commando’s
Correctie PO- / ALC-metercorrectie
Serverfunctie Ondersteunt serververbinding via Hamlib rigctld

Kenmerken

  • Werkt met Hamlib rigctld
  • Ondersteunt twee verbindingsmethoden: USB Serial(Server) / Network rigctld(Client)
  • Ondersteunt PO- / ALC-metercorrectie
  • Compatibel met macOS / Windows 11 / Raspberry Pi OS / Linux
Let op
  • Deze software is geen meetinstrument, maar een hulpmeter.
  • Wanneer andere applicaties of pc’s verbinding maken met Hamlib rigctld, gebruik dan Network rigctld bij Connection Type.

USB(Server)-modus

In USB Serial(Server)-modus start toy_meter Hamlib rigctld op de lokale pc en communiceert met de radio.

Meerdere toy_meter-instanties op dezelfde pc gebruiken

Op dezelfde pc kunnen maximaal 4 toy_meter-instanties in USB(Server)-modus gelijktijdig worden uitgevoerd.

Beschikbare poortnummers zijn:

toy_meter PORT
1e instantie 4532
2e instantie 4534
3e instantie 4536
4e instantie 4538

Wanneer meerdere radio’s gelijktijdig op dezelfde pc worden bewaakt, gebruik dan verschillende poortnummers voor elke radio.

Meerdere toy_meter-instanties starten

Om meerdere toy_meter-instanties te gebruiken, kopieert u het programma en geeft u elke kopie een andere bestandsnaam.

Bijvoorbeeld, u kunt ze benoemen naar het radiomodel:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

Configureer in elke toy_meter afzonderlijk de radio, seriële poort, communicatiesnelheid en rigctld-poortnummer.

Let op

Dezelfde seriële poort kan niet door meerdere toy_meter-instanties worden gebruikt. Verbind elke toy_meter met een andere radio en seriële poort.

Gebruikte poort controleren

Wanneer meerdere toy_meter-instanties worden gestart, kunt u het nummer van de momenteel gebruikte poort controleren in de titel van het meterpaneel [USB:453x].

Bovenaan het paneel wordt bijvoorbeeld weergegeven: 

ToyMeter V2.0 [USB:4532]

Hiermee kunt u zien welke USB(Server)-poort door elke toy_meter wordt gebruikt.

SETUP (Instellingen)

Connection Type (Verbindingsmethode)

Item Beschrijving
USB Serial (Server) Voor het bedienen van een via USB aangesloten radio met rigctld op de lokale pc. toy_meter start rigctld.
Network rigctld (Client) Voor verbinding via netwerk met een andere pc waarop Hamlib rigctld draait.

Radio Setting (Radio-instellingen)

Item Beschrijving.1 Beschrijving.2
MFG / MODEL / RF POWER RANGE Instellen volgens de radio
OPERATING MODE Normal Normale werking
Monitor Beschikbare meterfuncties worden in groen weergegeven. Wordt ook gebruikt voor PO- / ALC-metercorrectie. In USB(Server)-modus kunt u de gebruikte poort controleren.
Debug Alleen voor debugging (kan de respons vertragen)

RF REFERENCE (PO-metercorrectie)

Item Procedure
RF REFERENCE STEP-1. Stel OPERATING MODE in op Monitor
STEP-2. Zend op 25% van het maximale vermogen (FM-modus aanbevolen)
STEP-3. Klik op de groene “PO” om te corrigeren
STEP-4. Pas indien nodig de correctiewaarde handmatig aan (stappen 1–3 zijn niet verplicht)

ALC REFERENCE (ALC-metercorrectie)

Item Procedure
ALC REFERENCE STEP-1. Stel OPERATING MODE in op Monitor
STEP-2. Zend zodat de ALC-waarde van de radio iets onder de bovengrens blijft (WSJT-X aanbevolen)
STEP-3. Klik op de groene “ALC” om te corrigeren
STEP-4. Pas indien nodig de correctiewaarde handmatig aan (stappen 1–3 zijn niet verplicht)

Hieronder staat een voorbeeld van de ALC-meter van de radio. Stel af zodat de naald iets boven het ▲-teken staat.

Let op: PO- / ALC-meters verschillen sterk per radiomodel. Gebruik ze alleen als richtlijn.

Serial Port Setting (Seriële poortinstellingen)

Item Beschrijving.1 Beschrijving.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Instellen volgens de radio
SCAN_SP 0.1 〜 0.5 Hoe lager de waarde, hoe sneller de naald reageert. Voor oudere pc’s of radio’s wordt een hogere waarde aanbevolen.

Let op: Bij communicatieproblemen wordt het Setup-scherm automatisch geopend.

Network rigctld (Netwerkverbinding)

Item Beschrijving.1 Beschrijving.2
HOST IP ADDRESS IP-adres van de pc(Server) waarop Hamlib rigctld draait. Bij lokaal gebruik: leeg laten of 127.0.0.1.
PORT PORT NO Poortnummer van de pc(Server) waarop Hamlib rigctld draait. Standaard is 4532.

Referentie: Bij gebruik van Server moet toy_meter aan de serverzijde Connection Type op USB Serial(Server) hebben ingesteld. In de clientapplicatie geeft u het IP-adres en poortnummer op van de pc waarop toy_meter draait.

Voorbeeld: 

192.168.1.100:4532

Custom Functions (Aangepaste functies)

Item Beschrijving.1 Beschrijving.2
FNCx Eerste parameter Weergavelabel (max. 7 tekens)
Tweede parameter Besturingscommando (max. 16 tekens)

Let op: Deze functie is geïmplementeerd voor nieuwe YAESU CAT-commando’s. Werking met andere radio’s is niet gegarandeerd.

  • Niet compatibel met commando’s die een antwoord vereisen.
  • Als een commando lang duurt, kan het Setup-scherm worden geopend. Gebruik van dergelijke commando’s wordt afgeraden.
  • Gebruik alleen als u de communicatiespecificaties (CAT-commando’s) van de radio begrijpt.

Setup & Exit (Instellingen en afsluiten)

Item Beschrijving
Rechts onder JP1RXQ Setup-scherm
Links boven S Afsluiten (alleen voor Raspberry Pi 320×480-display)
Rechts boven W TUNE (alleen voor nieuwe YAESU CAT-commando’s)

Ondersteunde omgeving

Hamlib / rigctld is vereist voor de communicatie met de zendontvanger.
