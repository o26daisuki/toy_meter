toy_meter Version 2.0

Setup Utility

Übersicht

toy_meter ist eine einfache Meter-Anwendung zur Anzeige des Betriebszustands von Amateurfunkgeräten.

Über Hamlib werden die SIG-, PO-, SWR- und ALC-Meter angezeigt.

Hauptfunktionen

Funktion Inhalt
Meter SIG / PO / SWR / ALC
VFO-Anzeige Anzeige der aktuell verwendeten VFO-Frequenz (unter 1000 MHz)
TIME-Anzeige UTC / Local Time
FNC Senden neuer YAESU-CAT-Befehle
Kalibrierung PO-/ALC-Meter-Kalibrierung
Server-Funktion Unterstützung der Server-Verbindung über Hamlib rigctld

Merkmale

  • Betrieb mit Hamlib rigctld
  • Unterstützung von zwei Verbindungsarten: USB Serial(Server) / Network rigctld(Client)
  • Unterstützung der PO-/ALC-Meter-Kalibrierung
  • Unterstützung von macOS / Windows 11 / Raspberry Pi OS / Linux
Hinweis
  • Diese Software ist kein Messgerät, sondern ein Hilfsmeter.
  • Wenn Sie von einer anderen Anwendung oder einem anderen PC aus eine Verbindung zu Hamlib rigctld herstellen, wählen Sie bei Connection Type Network rigctld aus.

USB(Server)-Modus

Im USB Serial(Server)-Modus startet toy_meter Hamlib rigctld auf dem lokalen PC und kommuniziert mit dem Funkgerät.

Verwendung mehrerer toy_meter auf demselben PC

Auf demselben PC können im USB(Server)-Modus bis zu vier toy_meter gleichzeitig gestartet werden.

Die folgenden vier Portnummern können verwendet werden.

toy_meter PORT
1. Gerät 4532
2. Gerät 4534
3. Gerät 4536
4. Gerät 4538

Wenn mehrere Funkgeräte gleichzeitig auf demselben PC überwacht werden, verwenden Sie für jedes Gerät eine andere Portnummer.

So starten Sie mehrere toy_meter

Wenn Sie mehrere toy_meter verwenden, kopieren Sie das toy_meter-Programm und verwenden Sie für jede Kopie einen beliebigen Dateinamen.

Zum Beispiel können Sie die Namen der Funkgeräte verwenden:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

Konfigurieren Sie in jedem toy_meter Funkgerät, serielle Schnittstelle, Übertragungsgeschwindigkeit, rigctld-Portnummer usw. individuell.

Hinweis

Dieselbe serielle Schnittstelle kann nicht von mehreren toy_meter verwendet werden. Verbinden Sie jeden toy_meter mit einem anderen Funkgerät und einer anderen seriellen Schnittstelle.

Aktuell verwendete Portnummer prüfen

Wenn mehrere toy_meter gleichzeitig gestartet werden, können Sie im Titel des Meter-Panels [USB:453x] die Nummer des aktuell verwendeten Ports überprüfen.

Im Titel am oberen Rand des Panels wird beispielsweise Folgendes angezeigt. 

ToyMeter V2.0 [USB:4532]

Damit können Sie prüfen, welchen USB(Server)-Port der aktuell laufende toy_meter verwendet.

SETUP (Einstellungen)

Connection Type (Verbindungsart)

Option Beschreibung
USB Serial (Server) Wenn ein über USB angeschlossenes Funkgerät mit rigctld auf dem lokalen PC gesteuert wird. toy_meter startet rigctld.
Network rigctld (Client) Wenn Sie eine Verbindung zu Hamlib rigctld herstellen, das auf einem anderen PC o. Ä. läuft, erfolgt die Verbindung über das Netzwerk.

Radio Setting (Funkgeräteeinstellungen)

Option Beschreibung 1 Beschreibung 2
MFG / MODEL / RF POWER RANGE Entsprechend dem Funkgerät einstellen
OPERATING MODE Normal Normalbetrieb
Monitor Verfügbare Meter-Funktionen werden grün angezeigt. Wird auch zur Kalibrierung der PO-/ALC-Meter verwendet. Im USB(Server)-Modus kann außerdem die aktuell verwendete Portnummer geprüft werden.
Debug Nur für Debugging (die Reaktionsgeschwindigkeit wird bei Verwendung beeinträchtigt)

RF REFERENCE (PO-Meter-Kalibrierung)

Option Schritte
RF REFERENCE STEP-1. OPERATING MODE auf Monitor stellen
STEP-2. Mit 25 % der maximalen Ausgangsleistung senden (FM-Modus empfohlen)
STEP-3. Auf das grüne „PO“ klicken, um zu kalibrieren
STEP-4. Den Kalibrierwert bei Bedarf direkt anpassen (Die Einstellung ist auch ohne STEP-1 bis 3 möglich)

ALC REFERENCE (ALC-Meter-Kalibrierung)

Option Schritte
ALC REFERENCE STEP-1. OPERATING MODE auf Monitor stellen
STEP-2. So senden, dass der Wert etwas unter dem oberen Ende des zulässigen ALC-Bereichs des Funkgeräts liegt (Die Verwendung von WSJT-X o. Ä. wird empfohlen)
STEP-3. Auf das grüne „ALC“ klicken, um zu kalibrieren
STEP-4. Den Kalibrierwert bei Bedarf direkt anpassen (Die Einstellung ist auch ohne STEP-1 bis 3 möglich)

Unten sehen Sie eine Darstellung des ALC-Meters des Funkgeräts. Stellen Sie es so ein, dass die Nadel etwas über der Position ▲ liegt.

Hinweis: Da sich die PO-/ALC-Meter je nach Funkgerät stark unterscheiden, dienen die Werte nur als Richtwerte.

Serial Port Setting (Serielle Verbindungseinstellungen)

Option Beschreibung 1 Beschreibung 2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Entsprechend dem Funkgerät einstellen
SCAN_SP 0.1 〜 0.5 Je kleiner der Wert, desto besser reagiert die Nadel. Bei älteren PCs oder älteren Funkgeräten wird ein größerer Wert empfohlen.

Hinweis: Bei einem Kommunikationsfehler wird der Setup-Bildschirm automatisch geöffnet.

Network rigctld (Netzwerkverbindung)

Option Beschreibung 1 Beschreibung 2
HOST IP ADDRESS IP-Adresse des PCs (Server), auf dem Hamlib rigctld ausgeführt wird. Bei Local leer lassen oder 127.0.0.1 verwenden.
PORT PORT NO Portnummer des PCs (Server), auf dem Hamlib rigctld ausgeführt wird. Der Standardwert ist 4532.

Referenz: Wenn ein Server verwendet wird, setzt der toy_meter auf der Server-Seite Connection Type auf USB Serial(Server). In der Client-Anwendung geben Sie die IP-Adresse und PORT-Nummer des PCs an, auf dem toy_meter läuft.

Beispiel: 

192.168.1.100:4532

Custom Functions (Benutzerdefinierte Funktionen)

Option Beschreibung 1 Beschreibung 2
FNCx 1. Parameter Anzeigelabel (max. 7 Zeichen)
2. Parameter Steuerbefehl (max. 16 Zeichen)

Hinweis: Diese Funktion wurde für die neuen CAT-Befehle von YAESU implementiert. Für andere Funkgeräte wird keine Funktionsgarantie übernommen.

  • Befehle, die eine Antwort erfordern, werden nicht unterstützt.
  • Wenn die Wartezeit bis zum Abschluss eines Befehls zu lang ist, kann der Setup-Bildschirm geöffnet werden. Die Verwendung solcher Befehle wird nicht empfohlen.
  • Verwenden Sie diese Funktion nur, wenn Sie mit den Kommunikationsspezifikationen (CAT-Befehlen) des Funkgeräts vertraut sind.

Setup & Exit (Einstellungen und Beenden)

Option Beschreibung
Unten rechts JP1RXQ Setup-Bildschirm
Oben links S Beenden (nur für Raspberry-Pi-Displays mit 320×480)
Oben rechts W TUNE (nur für die neuen YAESU-CAT-Befehle)
