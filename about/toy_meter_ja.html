toy_meter Version 2.0

Setup Utility

概要

toy_meter はアマチュア無線機の運用状態を表示する簡易メーターアプリです。

Hamlib を介して SIG、PO、SWR、ALC メーターを表示します。

主な機能

機能 内容
メーター SIG / PO / SWR / ALC
VFO表示 運用中VFO周波数表示（1000MHz未満対応）
TIME表示 UTC / Local Time
FNC YAESU新CATコマンド送信
補正 PO / ALC メーター補正
Server 機能 Hamlib rigctld を利用した Server 接続に対応

特徴

  • Hamlib rigctld を利用して動作
  • USB Serial(Server) / Network rigctld(Client) の2種類の接続方式に対応
  • PO / ALC メーター補正対応
  • macOS / Windows 11 / Raspberry Pi OS / Linux 対応
注意
  • 本ソフトは測定器ではなく補助メーターです。
  • 他のアプリケーションやPCから Hamlib rigctld に接続する場合は、 Connection Type の Network rigctld を利用してください。

USB(Server) モード

USB Serial(Server) モードでは、toy_meter がローカルPC上で Hamlib rigctld を起動し、無線機と通信します。

複数の toy_meter を同一PCで使用する場合

同一PC上では、USB(Server)モードの toy_meter を 最大4つまで同時に起動できます。

使用できるポート番号は以下の4つです。

toy_meter PORT
1台目 4532
2台目 4534
3台目 4536
4台目 4538

同じPC上で複数の無線機を同時にモニターする場合は、 それぞれ異なるポート番号を使用してください。

複数の toy_meter を起動する方法

複数の toy_meter を使用する場合は、toy_meter のプログラムをコピーし、 それぞれ任意のファイル名を付けて使用できます。

例えば、以下のように無線機名を付けることができます。

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

それぞれの toy_meter で無線機、シリアルポート、 通信速度、rigctld のポート番号などを個別に設定して使用します。

注意

同じシリアルポートを複数の toy_meter で使用することはできません。 各 toy_meter は、それぞれ異なる無線機およびシリアルポートに接続してください。

使用中のポート番号を確認する

複数の toy_meter を起動した場合は、 メータパネルタイトルの [USB:453x] で使用中のポート番号を確認できます。

パネル上部のタイトルに、例えば以下のように表示されます。 

ToyMeter V2.0 [USB:4532]

これにより、現在動作している toy_meter が どの USB(Server) ポートを使用しているか確認できます。

SETUP (設定)

Connection Type (接続方式)

項目 説明
USB Serial (Server) USB接続された無線機をローカルPC上の rigctld で制御する場合。 toy_meter が rigctld を起動します。
Network rigctld (Client) 別のPCなどで動作している Hamlib rigctld に ネットワーク経由で接続する場合。

Radio Setting (無線機設定)

項目 説明.1 説明.2
MFG / MODEL / RF POWER RANGE 無線機に合わせて設定
OPERATING MODE Normal 通常運用
Monitor 利用可能なメーター機能を緑色で確認します。 PO / ALC メーターの補正にも使用します。 また、USB(Server)モードでは使用中のポート番号を確認できます。
Debug デバッグ専用（使用するとレスポンスが悪くなります）

RF REFERENCE (PO メーター補正)

項目 手順
RF REFERENCE STEP-1. OPERATING MODE を Monitor にする
STEP-2. 最大出力の25%で送信状態にします（FM Mode推奨）
STEP-3. 緑色の「PO」をクリックして補正
STEP-4. 必要に応じて補正値を直接調整します （STEP-1〜3を行わなくても設定できます）

ALC REFERENCE (ALC メーター補正)

項目 手順
ALC REFERENCE STEP-1. OPERATING MODE を Monitor にする
STEP-2. 無線機側のALC適正範囲の上限より少し下になるように送信します （WSJT-Xなど利用が推奨）
STEP-3. 緑色の「ALC」をクリックして補正
STEP-4. 必要に応じて補正値を直接調整します （STEP-1〜3を行わなくても設定できます）

下記は無線機側のALCメーターのイメージです。 針が▲の位置より少し上になるように調整します。

注意： PO / ALC メーターは無線機種による差が大きいため、 目安としてご利用ください。

Serial Port Setting (シリアル接続設定)

項目 説明.1 説明.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL 無線機に合わせて設定
SCAN_SP 0.1 〜 0.5 小さいほど針の応答性が向上します。 古いPC・古い無線機では大きめを推奨します。

注意： 通信異常時には、Setup画面が自動的に起動します。

Network rigctld (ネットワーク接続)

項目 説明.1 説明.2
HOST IP ADDRESS Hamlib rigctld 運用中 PC(Server) の IP アドレス。 Local時はブランクまたは 127.0.0.1。
PORT PORT NO Hamlib rigctld 運用中 PC(Server) の PORT番号。 デフォルトは 4532。

参考： Server を利用する場合、Server側の toy_meter は Connection Type を USB Serial(Server) とします。 接続元のアプリケーションでは、toy_meter が動作しているPCの IPアドレスとPORT番号を指定します。

例： 

192.168.1.100:4532

Custom Functions (カスタム機能)

項目 説明.1 説明.2
FNCx 第1パラメーター 表示ラベル（最大7文字）
第2パラメーター 制御コマンド（最大16文字）

注意： YAESU の新CATコマンド向けに実装した機能です。 他の無線機では動作保証はありません。

  • 応答を必要とするコマンドには対応しません。
  • コマンド完了までの待ち時間が長い場合、 Setup画面が開くことがあります。 このようなコマンドの使用はお勧めしません。
  • 無線機の通信仕様（CATコマンド）を理解している方のみご利用ください。

Setup & Exit (設定と停止)

項目 説明
右下 JP1RXQ 設定 (Setup) 画面
左上 S 終了（Raspberry Pi 320×480 ディスプレイ専用）
右上 W TUNE（YAESU新CAT専用）

対応環境

無線機との通信には Hamlib / rigctld が必要です。

環境 SCAN_SP 推奨値

Windows 11 0.1 〜 0.2
Raspberry Pi 3B+ 0.3 〜 0.5
接続速度 9600bps 0.3 〜 0.5
接続速度 38400bps 0.1 〜 0.3
