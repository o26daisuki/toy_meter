toy_meter Version 2.0

Setup Utility

Yhteenveto

toy_meter on yksinkertainen mittarisovellus, joka näyttää radioamatöörilähettimen käyttötilan.

Se näyttää SIG-, PO-, SWR- ja ALC-mittarit Hamlibin kautta.

Päätoiminnot

Toiminto Sisältö
Mittari SIG / PO / SWR / ALC
VFO-näyttö Käytössä olevan VFO-taajuuden näyttö (alle 1000 MHz)
TIME-näyttö UTC / Paikallinen aika
FNC YAESUn uudet CAT-komennot
Korjaus PO- / ALC-mittarin korjaus
Palvelintoiminto Tuki Hamlib rigctld -palvelinyhteydelle

Ominaisuudet

  • Toimii Hamlib rigctld -palvelun avulla
  • Tukee kahta yhteystapaa: USB Serial(Server) / Network rigctld(Client)
  • Tuki PO- / ALC-mittarin korjaukselle
  • Tukee macOS / Windows 11 / Raspberry Pi OS / Linux
Huomio
  • Tämä ohjelmisto ei ole mittalaite, vaan apumittari.
  • Jos muut sovellukset tai tietokoneet yhdistävät Hamlib rigctld -palveluun, käytä Connection Type -asetuksessa Network rigctld.

USB(Server)-tila

USB Serial(Server) -tilassa toy_meter käynnistää Hamlib rigctld -palvelun paikallisessa tietokoneessa ja kommunikoi lähettimen kanssa.

Useiden toy_meter -instanssien käyttö samassa tietokoneessa

Samassa tietokoneessa voidaan käynnistää enintään 4 toy_meter -instanssia USB(Server)-tilassa.

Käytettävissä olevat porttinumerot ovat seuraavat:

toy_meter PORT
1. laite 4532
2. laite 4534
3. laite 4536
4. laite 4538

Jos samassa tietokoneessa valvotaan useita lähettimiä samanaikaisesti, käytä eri porttinumeroa jokaiselle.

Useiden toy_meter -instanssien käynnistäminen

Jos haluat käyttää useita toy_meter -instansseja, kopioi ohjelma ja anna jokaiselle eri tiedostonimi.

Voit esimerkiksi nimetä ne lähettimen mallin mukaan:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

Kussakin toy_meter -instanssissa määritetään lähettimen asetukset, sarjaportti, siirtonopeus ja rigctld-porttinumero erikseen.

Huomio

Samaa sarjaporttia ei voi käyttää useissa toy_meter -instansseissa. Yhdistä jokainen toy_meter eri lähettimeen ja eri sarjaporttiin.

Käytössä olevan porttinumeron tarkistaminen

Kun useita toy_meter-ohjelmia käynnistetään, voit tarkistaa parhaillaan käytössä olevan porttinumeron mittaripaneelin otsikosta [USB:453x].

Paneelin yläosassa näkyy esimerkiksi: 

ToyMeter V2.0 [USB:4532]

Näin voit tarkistaa, mitä USB(Server)-porttia kukin toy_meter käyttää.

SETUP (Asetukset)

Connection Type (Yhteystapa)

Kohta Selitys
USB Serial (Server) Kun USB-liitettyä lähetintä ohjataan paikallisen tietokoneen rigctld-palvelulla. toy_meter käynnistää rigctld-palvelun.
Network rigctld (Client) Kun yhdistetään verkon kautta toiseen tietokoneeseen, jossa Hamlib rigctld toimii.

Radio Setting (Lähettimen asetukset)

Kohta Selitys.1 Selitys.2
MFG / MODEL / RF POWER RANGE Määritä lähettimen mukaan
OPERATING MODE Normal Normaali käyttö
Monitor Näyttää käytettävissä olevat mittaritoiminnot vihreänä. Käytetään myös PO- / ALC-mittarin korjaukseen. USB(Server)-tilassa voit tarkistaa käytössä olevan porttinumeron.
Debug Vianetsintätila (voi hidastaa vasteaikaa)

RF REFERENCE (PO-mittarin korjaus)

Kohta Vaiheet
RF REFERENCE STEP-1. Aseta OPERATING MODE tilaan Monitor
STEP-2. Lähetä 25 % maksimitehosta (FM-tila suositeltu)
STEP-3. Napsauta vihreää “PO”-painiketta korjataksesi
STEP-4. Tarvittaessa säädä korjausarvoa manuaalisesti (vaiheet 1–3 eivät ole pakollisia)

ALC REFERENCE (ALC-mittarin korjaus)

Kohta Vaiheet
ALC REFERENCE STEP-1. Aseta OPERATING MODE tilaan Monitor
STEP-2. Lähetä siten, että lähettimen ALC-alueen ylärajan alapuolelle jää hieman tilaa (WSJT-X suositeltu)
STEP-3. Napsauta vihreää “ALC”-painiketta korjataksesi
STEP-4. Tarvittaessa säädä korjausarvoa manuaalisesti (vaiheet 1–3 eivät ole pakollisia)

Alla on esimerkki lähettimen ALC-mittarista. Säädä niin, että neula on hieman ▲-merkin yläpuolella.

Huomio: PO- / ALC-mittarit voivat vaihdella suuresti lähettimen mallin mukaan. Käytä niitä vain suuntaa-antavana tietona.

Serial Port Setting (Sarjaportin asetukset)

Kohta Selitys.1 Selitys.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Määritä lähettimen mukaan
SCAN_SP 0.1 〜 0.5 Pienempi arvo parantaa neulan vasteaikaa. Vanhoissa tietokoneissa tai lähettimissä suositellaan suurempaa arvoa.

Huomio: Viestintävirheen sattuessa asetussivu avautuu automaattisesti.

Network rigctld (Verkkoyhteys)

Kohta Selitys.1 Selitys.2
HOST IP ADDRESS Tietokoneen (Server) IP-osoite, jossa Hamlib rigctld toimii. Paikallisessa käytössä jätä tyhjäksi tai käytä 127.0.0.1.
PORT PORT NO Tietokoneen (Server) porttinumero, jossa Hamlib rigctld toimii. Oletus on 4532.

Viite: Kun käytät Server-tilaa, aseta Server-puolen toy_meter Connection Type -asetukseen USB Serial(Server). Asiakasohjelmassa määritä toy_meterin tietokoneen IP-osoite ja porttinumero.

Esimerkki: 

192.168.1.100:4532

Custom Functions (Mukautetut toiminnot)

Kohta Selitys.1 Selitys.2
FNCx Ensimmäinen parametri Näyttölabeli (enintään 7 merkkiä)
Toinen parametri Ohjauskomento (enintään 16 merkkiä)

Huomio: Tämä toiminto on toteutettu YAESUn uusille CAT-komennoille. Toimivuutta muilla lähettimillä ei taata.

  • Ei tue komentoja, jotka vaativat vastausta.
  • Jos komennon suoritus kestää pitkään, asetussivu saattaa avautua. Tällaisten komentojen käyttöä ei suositella.
  • Käytä vain, jos ymmärrät lähettimen viestintäspesifikaatiot (CAT-komennot).

Setup & Exit (Asetukset ja lopetus)

Kohta Selitys
Oikea alakulma JP1RXQ Asetussivu (Setup)
Vasen yläkulma S Lopetus (vain Raspberry Pi 320×480 -näytölle)
Oikea yläkulma W TUNE (vain YAESUn uusille CAT-komennoille)
