toy_meter Version 2.0

Setup Utility

Panoramica

toy_meter è un’applicazione di misurazione semplice che mostra lo stato operativo di un ricetrasmettitore per radioamatori.

Visualizza i misuratori SIG, PO, SWR e ALC tramite Hamlib.

Funzioni principali

Funzione Contenuto
Misuratore SIG / PO / SWR / ALC
Visualizzazione VFO Visualizzazione della frequenza VFO in uso (compatibile con frequenze inferiori a 1000 MHz)
Visualizzazione TIME UTC / Ora locale
FNC Invio dei nuovi comandi CAT YAESU
Correzione Correzione dei misuratori PO / ALC
Funzione Server Supporto alla connessione Server tramite Hamlib rigctld

Caratteristiche

  • Funziona utilizzando Hamlib rigctld
  • Supporta due tipi di connessione: USB Serial(Server) / Network rigctld(Client)
  • Supporto alla correzione dei misuratori PO / ALC
  • Compatibile con macOS / Windows 11 / Raspberry Pi OS / Linux
Nota
  • Questo software non è uno strumento di misura, ma un misuratore ausiliario.
  • Se altre applicazioni o PC si collegano a Hamlib rigctld, utilizzare Network rigctld in Connection Type.

Modalità USB(Server)

In modalità USB Serial(Server), toy_meter avvia Hamlib rigctld sul PC locale e comunica con il ricetrasmettitore.

Utilizzo di più istanze di toy_meter sullo stesso PC

Sul medesimo PC è possibile avviare fino a 4 istanze di toy_meter in modalità USB(Server) contemporaneamente.

I numeri di porta disponibili sono i seguenti:

toy_meter PORT
1ª unità 4532
2ª unità 4534
3ª unità 4536
4ª unità 4538

Se si monitorano più ricetrasmettitori contemporaneamente sullo stesso PC, utilizzare numeri di porta diversi per ciascuno.

Come avviare più istanze di toy_meter

Per utilizzare più toy_meter, copiare il programma e assegnare a ciascuna copia un nome di file diverso.

Ad esempio, è possibile assegnare nomi basati sul modello del ricetrasmettitore:

toy_meter_FTDX10
toy_meter_FT818
toy_meter_FT857
toy_meter_FTDX101

In ciascuna istanza configurare separatamente il ricetrasmettitore, la porta seriale, la velocità di comunicazione e il numero di porta rigctld.

Nota

Non è possibile utilizzare la stessa porta seriale in più istanze di toy_meter. Collegare ogni toy_meter a un ricetrasmettitore e a una porta seriale diversi.

Verifica del numero di porta in uso

Quando vengono avviate più istanze di toy_meter, è possibile verificare il numero della porta attualmente in uso nel titolo del pannello del misuratore [USB:453x].

Nella parte superiore del pannello verrà visualizzato, ad esempio: 

ToyMeter V2.0 [USB:4532]

Questo permette di verificare quale porta USB(Server) è utilizzata da ciascuna istanza.

SETUP (Impostazioni)

Connection Type (Tipo di connessione)

Voce Descrizione
USB Serial (Server) Per controllare un ricetrasmettitore collegato via USB tramite rigctld sul PC locale. toy_meter avvia rigctld.
Network rigctld (Client) Per collegarsi tramite rete a un altro PC che esegue Hamlib rigctld.

Radio Setting (Impostazioni del ricetrasmettitore)

Voce Descrizione.1 Descrizione.2
MFG / MODEL / RF POWER RANGE Impostare in base al ricetrasmettitore
OPERATING MODE Normal Uso normale
Monitor Mostra in verde le funzioni di misurazione disponibili. Utilizzato anche per la correzione dei misuratori PO / ALC. In modalità USB(Server) consente di verificare la porta in uso.
Debug Modalità di debug (può rallentare la risposta)

RF REFERENCE (Correzione del misuratore PO)

Voce Procedura
RF REFERENCE STEP-1. Impostare OPERATING MODE su Monitor
STEP-2. Trasmettere al 25% della potenza massima (modalità FM consigliata)
STEP-3. Fare clic su “PO” in verde per correggere
STEP-4. Regolare manualmente il valore di correzione se necessario (gli step 1–3 non sono obbligatori)

ALC REFERENCE (Correzione del misuratore ALC)

Voce Procedura
ALC REFERENCE STEP-1. Impostare OPERATING MODE su Monitor
STEP-2. Trasmettere in modo che l’indicatore ALC del ricetrasmettitore rimanga leggermente sotto il limite superiore dell’intervallo appropriato (WSJT-X consigliato)
STEP-3. Fare clic su “ALC” in verde per correggere
STEP-4. Regolare manualmente il valore di correzione se necessario (gli step 1–3 non sono obbligatori)

Di seguito è mostrato un esempio del misuratore ALC del ricetrasmettitore. Regolare affinché la lancetta si trovi leggermente sopra il simbolo ▲.

Nota: I misuratori PO / ALC possono variare notevolmente a seconda del modello del ricetrasmettitore. Utilizzarli solo come riferimento.

Serial Port Setting (Impostazioni della porta seriale)

Voce Descrizione.1 Descrizione.2
SERIAL PORT / BAUD RATE / DATA BITS / PARITY / STOP BITS / FLOW CONTROL Impostare in base al ricetrasmettitore
SCAN_SP 0.1 〜 0.5 Un valore più basso migliora la reattività della lancetta. Per PC o ricetrasmettitori più vecchi si consiglia un valore più alto.

Nota: In caso di errore di comunicazione, la schermata di configurazione si aprirà automaticamente.

Network rigctld (Connessione di rete)

Voce Descrizione.1 Descrizione.2
HOST IP ADDRESS Indirizzo IP del PC(Server) che esegue Hamlib rigctld. In locale, lasciare vuoto o utilizzare 127.0.0.1.
PORT PORT NO Numero di porta del PC(Server) che esegue Hamlib rigctld. Predefinito: 4532.

Riferimento: Quando si utilizza la modalità Server, impostare Connection Type su USB Serial(Server) sul lato server. Nell’applicazione client, specificare l’indirizzo IP e il numero di porta del PC che esegue toy_meter.

Esempio: 

192.168.1.100:4532

Custom Functions (Funzioni personalizzate)

Voce Descrizione.1 Descrizione.2
FNCx Primo parametro Etichetta di visualizzazione (max. 7 caratteri)
Secondo parametro Comando di controllo (max. 16 caratteri)

Nota: Funzione implementata per i nuovi comandi CAT YAESU. Non è garantito il funzionamento con altri ricetrasmettitori.

  • Non supporta comandi che richiedono una risposta.
  • Se il tempo di esecuzione del comando è lungo, la schermata di configurazione potrebbe aprirsi. Si sconsiglia l’uso di tali comandi.
  • Utilizzare solo se si comprendono le specifiche di comunicazione (comandi CAT) del ricetrasmettitore.

Setup & Exit (Impostazioni e uscita)

Voce Descrizione
In basso a destra JP1RXQ Schermata di configurazione (Setup)
In alto a sinistra S Uscita (solo per display Raspberry Pi 320×480)
In alto a destra W TUNE (solo per i nuovi comandi CAT YAESU)

Ambiente supportato
